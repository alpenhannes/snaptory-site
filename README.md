# snaptory-site

Public web pages for the Snaptory iOS app: the privacy policy and support page that
App Store Connect requires, plus a small landing page.

Served by GitHub Pages. The source of truth is `site/` in the (private) Snaptory app
repo — edit there and copy across, so the pages don't drift from what the app does.

- `privacy.html` — App Store "Privacy Policy URL"
- `support.html` — App Store "Support URL"
- `index.html` — App Store "Marketing URL"
